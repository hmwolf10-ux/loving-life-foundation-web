# Website UI Kit — The Loving Life Foundation

High-fidelity click-through recreation of a proposed public website: Home, Scholarship, Golf Tournament, Zach's Story, Donate, plus shared Header/Footer.

Run by opening `index.html`. Current screen and form state persist across refreshes (localStorage).

## Caveats
- No existing website was provided — this is a **proposed direction**, grounded in the brand's real graphics and photography, not a copy of a live site.
- Icons are Lucide (flagged substitution — see readme.md Iconography).
- Past-recipient names, stats, and dates are illustrative placeholders.
